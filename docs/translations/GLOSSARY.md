# Glossary

How Vědomé utrácení (Mindful Spending) speaks in each language, and the names
it uses for its own things. Czech is the source; translations follow these
names so that a button, a tip and a workshop question that mean the same
thing also say the same thing. Change a name here first, then everywhere it
appears (`npm run translations:export` lists the texts).

## Voice

- **One person, informally.** The app speaks to one person as a friend would:
  Czech *ty*, English *you*, Polish *ty*, Ukrainian *ти*, Spanish *tú*.
  Never *Pan/Pani*, *Ви* or *usted*, not even on the PIN screen or in an
  error.
- **A group only in the workshop.** Questions a facilitator asks a whole group
  use the plural: Czech *vy*, Polish *wy*, Ukrainian *ви*, Spanish
  *vosotros* (see the open question in [es.md](es.md)).
- **Calm and warm.** No shaming, no pushing, no exclamation marks to hurry
  anyone. Short sentences.
- **Where Czech has to choose a gender,** the Czech source speaks to a woman
  (*Věděla jsi?*, *Jak ses cítila…*, the reflection questions in the first
  person). Polish and Ukrainian follow it; English and Spanish stay neutral
  where they can. Never add a gender the Czech text does not have: Czech
  *Vítej zpět* is Spanish *Hola de nuevo*, not *Bienvenida de nuevo*.

## Numbers, money and placeholders

- Amounts stay in Czech crowns, **Kč**, in every language; the app never
  converts them.
- Percentages: a no-break space before %, as in Czech (*100 %*). Whether
  Polish should write *100%* instead is an open question in [pl.md](pl.md).
- Keep everything in braces exactly as it is: `{v}`, `{n}`, `{name}`,
  `{goal}`… The app puts numbers and names there, and a test checks that each
  translation has the same ones as the Czech text.

When a text refers to a place in the app, it uses these names with the arrow
the app uses: *Více → Data*, *More → Data*, *Więcej → Dane*,
*Більше → Дані*, *Más → Datos*. In Polish and Ukrainian the names are
declined as ordinary words (*w Planie*, *у Плані*); Polish and Ukrainian
decline *ja* and *я* as neuter nouns (*przyszłego ja*, *майбутнього я*).

On the iPhone, Apple's own words for the home screen are *ekran początkowy*
and *початковий екран*; the steps that name Apple's buttons use them.

## Deleting

Spanish says *Borrar* for data and the workshop and *Eliminar* for one item;
Polish *Usuń*, Ukrainian *Видалити* throughout.

## What this is

Vědomé utrácení (Mindful Spending) is a calm, local-first 50/30/20 money-planning PWA by Usnea communitas, z. s., used on its own and in financial-literacy workshops. Plain React 18 without a framework and without a server: all data lives in the browser's `localStorage`. Live at <https://vedome-utraceni.vercel.app/>; Vercel deploys `main`.

## Source and generated files

- Edit the `.jsx` sources (`fa-*.jsx`, `ios-frame.jsx`, `tweaks-panel.jsx`), `index.html` (the whole design system lives in its CSS) and `sw.js`.
- `app.js` and `vendor/` are generated by `npm run compile` and committed. Never edit them by hand.
- `npm run compile` also stamps the content hash of `app.js` into `index.html` (`app.js?v=…`) and `sw.js`; commit those files with it.
- UI strings live in `fa-i18n.jsx`: the Czech text is the key, and every entry needs `en`, `pl`, `uk` and `es`.

## Before committing

```sh
npm ci                 # once
npm run compile        # after any .jsx change; commit app.js, index.html and sw.js
npm test               # unit, translation and build checks (about a second)
npm run test:e2e       # Chromium smoke test; first run: npx playwright install chromium
```

CI (`.github/workflows/ci.yml`) runs the same checks: the compile output must match the committed files, `npm test` must pass, and the smoke test runs in a second job.

When you change screens, look at a phone width (360–430 px) and a laptop window (the desktop phone frame scales to the window), in English and Czech, and in both themes if you touched styling.

## Product decisions (do not change without the maintainer)

- English is the default interface language; Czech and the other languages are chosen on the welcome screen or under More → Language.
- No server, account, analytics or network calls with user data. The PIN is a convenience lock, not encryption ([SECURITY.md](SECURITY.md)).
- A static site with no build step on the host; amounts are in Kč; Czech texts address the user informally ("ty").

## Conventions

- Small, focused commits with a short imperative English subject ("Fit the phone frame to laptop screens") and the reason in the body.
- No drive-by refactors or reformatting of untouched code.
- Accessibility is part of done: controls reachable by keyboard with visible focus, named inputs, text contrast of at least 4.5:1, and `prefers-reduced-motion` respected.
- Design work: the Impeccable design skill is installed for Claude Code (`.claude/skills/`) and Codex (`.agents/skills/`) with hooks that check UI edits; [PRODUCT.md](PRODUCT.md) is its brief.
